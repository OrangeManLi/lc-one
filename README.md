# 韭菜生存记 · Trader Quest

一个无需账号、打开就能玩的股票题材策略小游戏。10 万虚拟本金，30 个交易日，挑战 15 万总资产，并与三名电脑对手争夺街区排名。

## 玩法

- **操盘**：6 只虚构股票、日 K / 走势、5 / 10 日均线、持仓和交易记录。每笔交易为 100 股的整数倍，手续费 0.03%（最低 5 元），实行 T+1。
- **策略卡**：先知雷达透视所选股票的次日涨跌；金钟罩补回次日持仓损失的 50%（上限 3,000 元）；牛市号角为所选股票次日涨幅额外增加 3.5 个百分点。
- **收盘事件**：选择看涨、看跌或免费跳过老王的挑战。普通挑战猜对净赚 1,500 元、猜错损失 500 元；每 5 天的关卡挑战奖励 3,500 元、风险 1,000 元。
- **闯关补给**：第 5、10、20 天每种卡牌补充 1 张。首笔交易、同时持有 3 只股票、累计 5 笔交易、总资产达到 11 万，均有一次性成就奖励。
- **反馈**：像素小牛、成长称号、电脑对手排名、每日战报、可开关音效、30 日最终结算和历史最佳收益。
- **自动存档**：游戏状态保存在当前浏览器的 `localStorage`。刷新可继续；同源标签页会同步进度。重新开局保留历史最佳收益。

全部股票、价格、新闻、技能、奖金和对手都是游戏模拟，不连接证券账户或实时金融数据。已使用的策略卡与随机状态也会存档，刷新不会重新生成行情。

## 本地开发

需要 Node.js 20+ 和 Python 3，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。请使用 HTTP 预览；浏览器直接打开 `file://` 页面可能无法加载 JavaScript 模块。

```sh
npm run check
npm test
npm run build
```

测试覆盖交易资金守恒、T+1、非法输入、整仓数量、30 日结算、确定性行情、存档验证、卡牌效果、事件奖惩和成就补给。`dist/` 为可发布静态产物。

## 文件

| 文件                  | 用途                              |
| --------------------- | --------------------------------- |
| `index.html`          | 页面和游戏弹窗                    |
| `styles.css`          | 桌面、平板、手机布局与游戏视觉    |
| `game.mjs`            | 可独立测试的交易与游戏规则        |
| `app.mjs`             | 交互、Canvas 图表、音效、存档     |
| `mascot.svg`          | 项目内绘制的像素小牛              |
| `tests/game.test.mjs` | Node 内置测试，无第三方测试框架   |
| `scripts/build.mjs`   | 将 7 个必需静态文件输出到 `dist/` |

不依赖外部脚本、图片或字体，使用系统字体；没有 WebGL 要求。适配手机底部导航、常驻收盘入口、键盘操作和减少动态效果偏好。

## 部署

沿用 `OrangeManLi/lc-one` 的 Cloudflare Pages 和域名 https://lc-one.cn/ 。推送到 `main` 后，GitHub Actions 校验、测试、构建，再将 `dist/` 部署到 `lc-one` 项目。只发布游戏所需文件。

仓库需保留已有 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID` Actions secrets，配置见 `.github/workflows/deploy.yml`。部署步骤见 [GITHUB_GUIDE.md](GITHUB_GUIDE.md)。
